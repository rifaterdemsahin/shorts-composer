Updates

Changelog for the server-side pipeline and pages.
Latest

Real background removal via MediaPipe selfie segmentation Fix

  • The bundled default-aroll.webm has no alpha channel and was shot against a plain brown wall, not a green screen — flat RGB-distance chroma keying couldn't separate that backdrop from skin tones and left visible cutout artifacts on the face/hands.
  • Replaced it with real per-frame person segmentation (segmentation.py, MediaPipe selfie_segmenter.tflite) that builds an accurate alpha mask for the speaker and composites it over the background image with OpenCV, before the original audio is reattached and subtitles are burned in.
  • config.json's chroma_key.method now supports "segmentation" (default, for real-world non-green-screen footage) or "color" (the original RGB-distance keying, for real green/blue-screen footage).
Earlier

Shared navigation, footer, and a pipeline test page Feature

  • Added a shared top nav and footer (Editor / Pipeline Test / Updates / GitHub / Live Demo) across all pages.
  • Added /test with live pipeline stage indicators, a searchable/filterable live log stream, the rendered output, and the Whisper verification report — backed by new /api/run and /api/status endpoints.
  • Bundled default demo assets (background image, a-roll) directly into assets/ and wired them into config.json so the pipeline runs out of the box.
  • Ported composer.py to the moviepy 2.x API and generated real subtitles/ground-truth script from the a-roll's actual narration via Whisper.
